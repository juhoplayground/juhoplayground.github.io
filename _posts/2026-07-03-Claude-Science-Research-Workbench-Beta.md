## 개요

Anthropic이 생명과학 연구자를 위한 통합 워크벤치 앱 Claude Science를 공개 베타로 출시했다.
Claude Science는 새로운 모델이 아니라, 기존 Claude 모델에 과학 도구와 데이터베이스를 연결한 애플리케이션이다.
데이터 정제부터 논문 발표까지 연구의 모든 단계를 추적하며, 엄격한 과학을 지원하는 연구 파트너를 지향한다.

## 주요 기능

### 재현 가능한 과학 아티팩트

Claude Science의 핵심 가치는 재현성이다.
모든 결과물에는 정확한 코드, 실행 환경, 대화 기록이 함께 저장되어 수개월 후에도 재현, 편집, 검증이 가능하다.
원시 데이터는 사용자 인프라에 로컬로 유지되어 데이터 통제권을 보장한다.

### 검증과 시각화

Claude Science는 자동 검증 시스템을 갖춰 잘못된 인용이나 추적 불가능한 수치를 감지하고, 코드와 그림 간의 불일치를 확인한다.
과학 특화 렌더러는 단백질, 유전체 트랙, 화학 구조, PDF를 추가 설치 없이 기본 지원한다.

주요 기능을 정리하면 다음과 같다.

| 기능 | 설명 |
|------|------|
| 자동 검증 | 잘못된 인용, 추적 불가 수치, 코드-그림 불일치 감지 |
| 과학 렌더러 | 단백질, 유전체 트랙, 화학 구조, PDF 기본 지원 |
| 그림 편집 | 그림에 주석을 달면 AI가 기반 코드를 읽고 직접 수정 |
| 통합 문서 작성 | 분석 결과와 함께 논문 작성, Markdown과 LaTeX 미리보기 |

## 기술적 특징

### 계산 환경 관리

Claude Science는 다양한 실행 환경을 지원한다.
로컬 노트북, Linux 머신, HPC 클러스터, 클라우드 VM에서 실행할 수 있으며, GPU 1개부터 수백 개까지 확장 가능하다.
SSH를 통해 배치 스크립트를 작성·관리하고 Modal 계정 통합을 지원한다.
Python과 R 커널의 지속성을 유지해 변수, 데이터프레임, 로드된 모델이 메모리에 남아 빠른 반복 작업이 가능하다.

### 지원 분야와 데이터베이스

플랫폼은 여러 생명과학 분야에 사전 구성되어 있다.

| 분야 | 지원 내용 |
|------|-----------|
| 게노믹스 | 단일 세포 RNA-seq 분석 |
| 진화 생물학 | 계통 분석, 최대우도 트리 추론 |
| 구조 생물학 | 예측 구조, 도메인, 임상 변이 분석 |
| 케미인포매틱스 | 생물활성 데이터, 분자 설계 |
| 프로테오믹스 | 단백질 언어 모델 활용 |

60개 이상의 과학 데이터베이스를 쿼리할 수 있으며 문헌 읽기를 지원한다.

## 대상 사용자와 제공 범위

Claude Science는 계산 생물학자와 비계산 생물학자, 약물 발견·개발 연구원, 생명과학 분야 대학 연구자와 대학원생, 산업 연구소를 대상으로 한다.
기존 연구실 도구(ELN, 파이프라인, API)와의 통합을 통해 전문 도구들이 함께 작동하는 통합 워크벤치 역할을 수행한다.

제공 범위는 macOS(Apple Silicon 및 Intel)와 Linux이며, Pro, Max, Team, Enterprise 플랜에서 이용할 수 있다.
연구실용 할인 Claude Team 플랜도 제공된다.
한 연구자는 원본 데이터에서 출판 품질 그림까지 단일 세션에서 완성할 수 있다고 평가했고, MIT 생물학 교수는 이를 진정으로 혁신적이라고 언급했다.

## 결론

Claude Science는 데이터 정제, 분석, 검증, 논문 작성으로 이어지는 연구 흐름을 하나의 앱에 통합한다.
재현 가능한 아티팩트와 자동 검증, 과학 특화 렌더링을 통해 연구의 신뢰성과 생산성을 동시에 겨냥한 것이 특징이다.
공개 베타 단계인 만큼 실제 연구 현장에서의 검증이 앞으로의 관건이 될 것이다.
