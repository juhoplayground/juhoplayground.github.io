## 개요

Anthropic이 2026년 6월 30일 Claude Sonnet 5를 출시했다.
"가장 에이전트 지향적인 Sonnet 모델"로 설계되어, 도구 사용과 자율적 실행, 복잡한 작업 수행에서 큰 개선을 이뤘다.
핵심은 Sonnet 등급의 비용으로 Opus급에 가까운 에이전트 실행 능력을 제공한다는 점이다.

## 성능과 가격

### 벤치마크와 비용-성능 곡선

Claude Sonnet 5는 이전 모델인 Sonnet 4.6 대비 추론, 도구 사용, 코딩, 지식 기반 작업 전반에서 성능이 향상됐다.

| 평가 항목 | 개선 내용 |
|-----------|-----------|
| 추론 능력 | 실질적 향상 |
| 도구 활용 | 상당한 개선 |
| 코딩 작업 | 중대한 진전 |
| 지식 기반 작업 | 뚜렷한 발전 |

특히 effort(노력) 수준에 따라 비용-성능을 선택할 수 있는 것이 특징이다.
중간 노력 수준에서는 Opus 4.8 대비 비용 효율성이 크게 개선되고, 높은 노력 수준에서는 특정 작업에서 Opus 4.8 수준의 성능에 도달한다.
BrowseComp 평가에서 Sonnet 5는 Sonnet 4.6의 한계를 극복하고 더 넓은 비용-성능 옵션을 제공했다.

### 가격 정책

가격은 소개 기간과 표준 기간으로 나뉜다.

| 구분 | 입력(백만 토큰) | 출력(백만 토큰) |
|------|-----------------|-----------------|
| 소개 가격(8월 31일까지) | 2달러 | 10달러 |
| 표준 가격(9월 1일부터) | 3달러 | 15달러 |

새로운 토크나이저로 인해 동일 콘텐츠가 1.0에서 1.35배 더 많은 토큰으로 처리되지만, 소개 가격을 감안하면 대체로 비용 중립적이다.
표준 가격 기준으로도 Opus 4.8(입력 5달러, 출력 25달러)보다 약 40% 저렴하다.

## 주요 개선사항

### 에이전트 역량

Sonnet 5는 이전 Sonnet 모델이 중단하던 복잡한 작업을 끝까지 완료한다.
명시적 지시 없이 자체 출력을 검증하고, 멀티스텝 작업을 지속적으로 실행한다.
소프트웨어 엔지니어링에서는 지속적 코딩, 도구 사용, 복잡한 디버깅을 처리하고, 테스트 작성부터 구현·검증까지 단일 패스로 완료한다.
Salesforce 업데이트나 메시지 발송 같은 다단계 자동화 워크플로우, 수십 개의 도전적인 풀 리퀘스트를 검증된 결과까지 자동 처리하는 코드 리뷰 등이 대표 사례다.

### 안전성

안전성 측면에서도 개선이 이뤄졌다.
Sonnet 4.6보다 전반적으로 부정적 행동률이 낮고, 악의적 요청 거부 능력과 프롬프트 주입 공격에 대한 저항성이 향상됐으며, 환각과 무비판적 동의가 감소했다.
다만 Opus 4.8이나 Mythos Preview와 비교하면 오정렬 행동률이 약간 높아 개선 여지가 있다.

사이버보안 측면에서는 의도적으로 관련 작업을 학습시키지 않았다.
Firefox 익스플로잇 개발 평가에서 완전 성공률이 0%였으며, Opus 4.7/4.8 수준의 실시간 감지·차단이 기본 활성화된다.

## 제공 범위와 사용자 반응

Claude Sonnet 5는 Free와 Pro 플랜의 기본 모델로 제공되며, Max, Team, Enterprise에서도 사용할 수 있다.
Claude Code와 Claude Platform에 통합됐고, API에서는 claude-sonnet-5 모델명으로 접근한다.
높은 노력 수준의 토큰 사용량을 수용하기 위해 Chat, Cowork, Claude Code, Platform 전반에서 속도 제한이 상향됐다.

한편 Hacker News 등에서는 비판적 의견도 제기됐다.
중간에서 높은 노력 수준에서는 Opus와 비용이 비슷해지므로 차라리 Opus의 낮은 노력 수준을 선택하는 편이 낫다는 의견과, 에이전트 보조 개발에는 과도하게 설계됐다는 지적이 있었다.

## 결론

Claude Sonnet 5는 Anthropic의 에이전트 AI 흐름이 Sonnet 클래스까지 확대됐음을 보여주는 모델이다.
노력 수준으로 비용과 성능을 조절할 수 있게 하여, 몇 개월 전 더 크고 비싼 모델 수준의 자율 실행을 Sonnet 가격대에서 제공한다.
다만 높은 노력 수준에서의 비용 경쟁력과 오정렬 행동률은 사용자가 실사용에서 따져볼 지점이다.
